# Vanu Dashboard — protótipo visual

Este pacote contém a primeira versão visual do painel da Vanu.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `vanu-dashboard`.
3. Dê dois cliques em `index.html` (ou abra com Chrome/Edge).

## O que já funciona nesta prévia
- Navegação entre as seções do painel.
- Visão geral e cartões demonstrativos.
- Editor de mensagem embed com prévia ao vivo.
- Controles visuais de boas-vindas, autorole, tickets e verificação.
- Layout responsivo para celular e computador.

## Importante
Esta é uma prévia de frontend. Ainda NÃO tem login real do Discord, leitura de servidores, persistência no banco, nem publicação de mensagens no Discord. Os dados e indicadores são fictícios para demonstrar o visual e o fluxo. A próxima etapa técnica é criar OAuth2 seguro no servidor, banco de dados por guild e API para o bot. Nunca coloque o token do bot no navegador.
